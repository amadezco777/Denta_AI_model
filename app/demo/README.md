# Entrada técnica de demostración

`control_sintetico.png` es un patrón de niveles de gris generado mediante
`scripts/presentation/prepare_demo_inputs.py`. No es una radiografía y no
contiene información de pacientes. Puede cargarse para comprobar el recorrido
de archivo, procesamiento, visualización y descarga CSV. Sus predicciones no
forman parte de las métricas científicas ni acreditan desempeño clínico.

Los ejemplos radiográficos y las pruebas del estudio se verifican sobre el
corpus autorizado local, que no se distribuye con el proyecto.
